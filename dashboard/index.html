Token Launch Radar

Protocols that record no token yet, priced by the peers that already trade — and how to farm each one.

An implied value is this board's own claim: what a token would be worth if the protocol's record stayed as it is and the market priced it like its category. It is not a prediction that a token will be issued. A protocol "records no token" in the snapshot — that is DefiLlama's record, not proof none exists.
